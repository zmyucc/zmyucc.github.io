FreeRTOS之编写按钮驱动

发表于 2026-09-23

按钮松开时，读到的值是1；按钮按下时，读到的值是0。

上图，一开始按钮处于松开状态，因此读到引脚的值是1；之后按钮按下，读到的值变为0；再次松开，值有变为1。
因此，要捕捉按钮松开的瞬间，即值从0变为1的瞬间。

编写按钮代码

首先，FreeRTOS需要新建目录，让代码更加易于区分。新建User目录，在User目录下新建Task目录，在Task目录下新建Key_Task.c和Key_Task.h文件。

程序现象是，每次按下KEY1按钮，串口会发送一条KEY1 Clicked.

Q1：为什么在KeyTask()方法的for循环中要加vTaskDelay延迟，可以省略吗？
删掉该延迟后，KeyTask()方法无法进入阻塞，按钮任务始终执行，低优先级的任务没有执行的机会，因此不能省略。

Q2：为什么上方的按钮驱动程序没有消抖？
因为每次读取一次按钮状态后，要等10ms，而按钮抖动只有不到1ms，没有必要消抖。

编写通用按钮驱动程序

有时需要使用到多个按钮，为每个按钮单独编写程序很麻烦，而且难以维护。
因此需要编写通用按钮驱动程序。

驱动程序适合存放在Drivers文件夹中，因此在Drivers文件夹中创建key.c和key.h这2个文件。

key.h

程序现象是，按下KEY1按钮，串口会发送一条KEY1 Clicked.
按下KEY2按钮，串口会发送一条KEY2 Clicked.

拆分长代码

按照上面代码的逻辑，如果有多个按钮，可能会导致单个文件的代码过长，不容易维护。
因此需要把长代码拆分为多个文件。对key_task.c文件进行拆分。
例如有6个按钮，因此需要把key_task.c拆分为key1.c、key2.c、key3.c、key4.c、key5.c、key6.c。

在User文件夹下创建keys文件夹，把这些拆分的文件放在里面，专门存放不同按钮的代码。

Drivers -> key.c

User -> Tasks -> Key_Task.c

User -> Keys ->key1.c

其他按钮的程序与key1类似，不再赘述。
